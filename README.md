# advertisements

WIPA ADS — Advertising portal for the Women's IP World Alliance community.

## Features
- **Hero Simulation**: Real-time Three.js WebGL Navier-Stokes liquid-chrome fluid displacement & difference blend mode.
- **How It Works**: Transparent £2/credit pricing, 4:1 feed cadence breakdown, tiered packages, and interactive credit calculator.
- **Advertiser Portal**: Mock authentication (`username: 1`, `password: 1`) and account creation with persistent session management.
- **Advertiser Dashboard**: Credit balances, total in-feed impressions, CTR metrics, and live campaign status.
- **Full-Page Precision Analytics**: Per-ad KPI metrics, 7-day daily impression breakdown, audience seniority charts, and top geographic hubs.
- **Full-Page Creative Editor**: Real-time live feed card preview simulator, banner uploader, destination URL, and delivery status control.

## Running Locally
```bash
node server.js
```
Open [http://localhost:3344](http://localhost:3344) in your browser.
